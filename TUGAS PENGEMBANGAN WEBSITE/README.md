# Portofolio Pribadi — Tugas UI/UX

Website portofolio pribadi berbasis HTML, CSS, dan JavaScript yang dibuat untuk memenuhi tugas mata kuliah UI/UX.

---

# Deskripsi Website

Website ini dirancang sebagai media untuk menampilkan profil pribadi, kemampuan, proyek, dan informasi kontak secara profesional dengan menerapkan prinsip-prinsip UI/UX modern.

Website menggunakan desain minimalis modern dengan fokus pada:
- konsistensi visual
- kemudahan navigasi
- keterbacaan
- pengalaman pengguna
- responsivitas di berbagai perangkat

---

# Fitur Website

- Responsive Design
- Sticky Navigation Bar
- Mobile Hamburger Menu
- Smooth Scrolling
- Skill Progress Animation
- Modern Card Layout
- Contact Form Feedback
- UI Modern & Clean

---

# Penerapan Prinsip UI/UX

| Prinsip | Implementasi |
|---|---|
| Konsistensi Desain | Penggunaan warna, font, tombol, dan card yang seragam |
| Navigasi Jelas | Navbar sticky dengan menu navigasi sederhana |
| Layout Rapi | Menggunakan CSS Grid & Flexbox untuk struktur yang teratur |
| Responsif | Tampilan menyesuaikan ukuran layar HP, tablet, dan laptop |
| Visual Hierarchy | Perbedaan ukuran heading, warna, dan spacing |
| Feedback Pengguna | Hover effect dan feedback form setelah submit |
| Tipografi | Menggunakan font modern dan mudah dibaca |
